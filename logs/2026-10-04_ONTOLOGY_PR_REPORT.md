## Reading

- **The stage-2 judge filter cost recall.** Recall fell from 0.805 (provenance only) to 0.546; the same filter gives the untyped pipeline 0.540. With the benchmark wrapper removed, Kev-0.8B-ft's `instruction_override` question at 0.5 rejects many source passages of successful attacks. Thresholds 0.3 / 0.7 (descriptive): recall 0.574 / 0.506.
- **Against the same pipeline without the ontology**, precision was higher (0.759 vs 0.691, p 0.019), but recall non-inferiority was not established (p 0.12), and random typing of the same sizes reached a mean precision of 0.720 (p 0.19). Route V (value recognisers) and the judge filter are shared by both arms and are not credited to the ontology.
- **Descriptive only (ablations and cross-cohort pattern, not registered):** ontology-typed candidates *without* the judge (stage 1 only) give precision 0.629 at recall 0.796, against 0.511 / 0.805 for provenance only. The same direction appeared on every held-out cohort so far: v2 (M-OTP vs B-prov, 3 544 runs), E-AL (3 630 runs: precision 0.290 → 0.380, recall 0.745 → 0.724) and here M-OTP 0.640 / 0.787. No pre-registered test has yet confirmed it with a bounded recall loss.
- Injection-text-overlap proxy (secondary): M-2S precision 0.891, recall 0.614; B-prov 0.577 / 0.871.
- Tiers (descriptive): irreversible — B-prov 514 alerts / 369 true, M-2S 373 / 302; other — B-prov 1094 / 452, M-2S 361 / 255.
- Source-trust ablation (blind source binding instead of the judge): precision 0.691, recall 0.425.

Benchmark runs only (AgentDojo; same tasks as earlier cohorts, different agent models). Not a validated tiered gate policy; not general runtime safety.
